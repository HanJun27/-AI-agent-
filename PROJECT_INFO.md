# GitHub Pages建议（可选）

如果需要展示项目Demo，可以启用GitHub Pages：

1. 在 `frontend/` 目录构建静态文件：
```bash
cd frontend
npm run build
```

2. 将 `dist/` 目录部署到GitHub Pages
3. 或使用Vercel/Netlify等现代部署平台
