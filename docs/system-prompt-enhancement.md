# System Prompt 强化说明

**修改时间**: 2026-05-09  
**修改文件**: `LLMAgentService.java`  
**目的**: 提高LLM工具选择的准确性和JSON输出格式的规范性

---

## 📋 强化内容总览

### 1. 新增"工具选择规则"章节 ⭐⭐⭐

在"工作流程"之后添加了详细的工具选择规则，明确告诉LLM如何根据用户意图选择正确的工具类型。

#### 添加操作
```
关键词："添加"、"创建"、"新增"、"插入"、"注册"
→ 使用 addXXX 工具
示例："添加一个学生" → addStudent
```

#### 修改操作
```
关键词："修改"、"改为"、"更新"、"变更"、"调整"、"设置"
→ 使用 updateXXX 工具
示例："把电话改为15862840271" → updateStudent
示例："把班级人数改为60" → updateClass
示例："把部门位置改为教学楼" → updateDepartment
```

#### 删除操作
```
关键词："删除"、"移除"、"注销"
→ 使用 deleteXXX 工具
示例："删除学生S2023001" → deleteStudent
```

#### 查询操作
```
关键词："查询"、"查找"、"搜索"、"查看"、"显示"
→ 使用 queryXXX 工具
示例："查询孙七的信息" → queryStudents
```

#### 分析操作
```
关键词："分析"、"统计"、"比例"、"分布"
→ 使用 analyzeXXX 工具
示例："分析学生性别分布" → analyzeStudentGender
```

---

### 2. 强化"输出格式"要求 ⭐⭐⭐

将标题从"非常重要"升级为"极其重要，必须遵守"，并增加了更多错误示例。

#### 修改前
```
❌ 错误示例：只返回 {"name":"孙七"} （缺少tool字段）
✅ 正确示例：{"tool":"queryStudents","params":{"name":"孙七"},"thought":"查询学生"}
```

#### 修改后
```
❌ 错误示例1：只返回 {"name":"孙七"} （缺少tool字段）
❌ 错误示例2：返回 queryStudents\n{"name":"孙七"} （不是有效JSON）
❌ 错误示例3：用户说"把班级人数改为60"，你返回 {"className":"TEST_CLASS"} 
              （应该用updateClass而非queryClasses）

✅ 正确示例1：{"tool":"queryStudents","params":{"name":"孙七"},"thought":"查询学生"}
✅ 正确示例2：{"tool":"updateClass","params":{"classNo":"C2023001","studentCount":60},
              "thought":"修改班级人数"}
✅ 正确示例3：{"tool":"analyzeStudentGender","params":{},"thought":"分析性别分布"}
```

**关键改进**：
- 增加了3个错误示例（从1个增加到3个）
- 增加了3个正确示例（从1个增加到3个）
- 特别强调了"修改操作不应被误解为查询"的问题

---

### 3. 强化"禁止行为"列表 ⭐⭐

将标题升级为"违反将导致系统错误"，并增加了具体的禁止项。

#### 修改前
```
## 🚫 禁止行为
1. 不要返回Markdown代码块
2. 不要返回解释文字 + JSON的混合内容
3. 不要只返回params而省略tool字段
4. 必须严格遵循JSON格式
```

#### 修改后
```
## 🚫 禁止行为（违反将导致系统错误）
1. ❌ 不要返回Markdown代码块（如 ```json ... ```）
2. ❌ 不要返回解释文字 + JSON的混合内容
3. ❌ 不要只返回params而省略tool字段
4. ❌ 不要把修改操作误解为查询操作
5. ❌ 不要把添加操作误解为查询操作
6. ✅ 必须严格遵循JSON格式
7. ✅ 必须包含tool字段
8. ✅ 必须根据用户意图选择正确的工具类型
```

**关键改进**：
- 从4条增加到8条
- 使用❌和✅符号增强视觉提示
- 明确指出了"修改/添加操作不应误解为查询"的问题

---

## 🎯 强化的核心目标

### 问题1：LLM工具选择不准确
**现象**：
- 用户说"把班级人数改为60"，LLM返回`queryClasses`而非`updateClass`
- 用户说"把部门位置改为教学楼"，LLM返回`queryDepartments`而非`updateDepartment`

**解决方案**：
- 添加工具选择规则，明确关键词映射
- 提供具体的正反示例

---

### 问题2：LLM输出格式不规范
**现象**：
- LLM返回`analyzeStudentGender\n{}`而非完整JSON
- LLM返回`queryStudents\n{"name":"孙七"}`而非完整JSON

**解决方案**：
- 增加多个错误示例，展示常见错误格式
- 强调必须包含`tool`字段
- 使用"极其重要，必须遵守"等强烈措辞

---

### 问题3：LLM对指令遵循不严格
**现象**：
- 虽然有System Prompt，但LLM经常忽略要求

**解决方案**：
- 使用更强烈的语气（"极其重要"、"违反将导致系统错误"）
- 使用视觉符号（❌✅）增强注意力
- 重复强调关键点（在多个章节中提及）
