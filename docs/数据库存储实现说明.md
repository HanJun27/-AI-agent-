## 🚀 启动步骤

### 第一步：确保MySQL数据库已启动并导入

```powershell
# 检查MySQL服务状态
Get-Service MySQL80

# 如果未启动，启动它
Start-Service MySQL80

# 验证数据库是否存在
mysql -u root -p206663021 -e "USE zijin_college; SHOW TABLES;"
```

### 第二步：编译并启动后端

**方式1：使用Maven命令**
```powershell
cd e:\工作台B\2026年春课设\java课设\zijin-college-system\backend
mvn clean package -DskipTests
java -jar target\college-system-1.0.0.jar
```

**方式2：使用IDEA**
1. 用IDEA打开backend文件夹
2. 等待Maven依赖下载完成
3. 找到 `ZijinCollegeApplication.java`
4. 点击运行按钮 ▶️

**方式3：使用VS Code**
1. 安装 Java Extension Pack
2. 打开backend文件夹
3. 按 F5 运行

### 第三步：启动前端

```powershell
cd e:\工作台B\2026年春课设\java课设\zijin-college-system\frontend
npm run dev
```

### 第四步：测试员工管理

1. 浏览器访问 http://localhost:3000

3. 点击左侧"人事管理"

## 🔧 如何完善其他模块

参照员工管理的实现模式：

### 1. 创建后端代码
```
Entity (已存在) → Mapper接口 → Mapper.xml → Service接口 → ServiceImpl → Controller
```

### 2. 创建前端API模块
```typescript
// src/api/class.ts
import request from './request'

export const getClasses = (params) => request.get('/classes', { params })
export const addClass = (data) => request.post('/classes', data)
// ...
```

### 3. 修改Vue组件
```typescript
import { getClasses, addClass, ... } from '@/api/class'

const loadClasses = async () => {
  const response = await getClasses({ pageNum, pageSize })
  classes.value = response.data.list
}
```

## ⚠️ 注意事项

1. **首次使用前必须启动后端**，否则前端会报错
2. **数据库表必须存在**，否则查询会失败
3. **员工编号必须唯一**，后端会进行验证
4. **跨域已配置**，前后端可以正常通信
