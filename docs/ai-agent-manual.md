# 紫金学院AI Agent对话系统使用说明

## 🚀 功能概述

紫金学院AI Agent对话系统是一个智能化的数据管理助手，具备以下核心功能：

### 1. 数据库查询功能
- **查询员工信息**：支持查询所有员工、特定员工信息
- **查询学生信息**：支持查询所有学生、特定学生信息  
- **查询班级信息**：支持查询所有班级、特定班级信息
- **查询部门信息**：支持查询所有部门、特定部门信息
- **数据库概览**：显示整体数据统计信息

### 2. 数据分析功能
- **员工分布分析**：按部门统计员工分布情况
- **学生性别比例**：分析学生性别比例及分布
- **班级规模分析**：统计各班级人数、平均规模等
- **学生年龄分布**：分析学生年龄分布及特点
- **综合分析报告**：生成全面的数据分析报告

### 3. 数据管理功能
- **添加数据**：支持添加员工、学生、班级信息
- **删除数据**：支持删除指定的员工、学生、班级信息

### 4. 自然语言交互
- 支持使用自然语言进行数据查询和分析
- 智能意图识别，自动匹配相应功能

## 📋 使用指南

### 前提条件
1. 确保后端服务已启动
2. 数据库已初始化并包含相关数据
3. （可选）在设置界面配置AI API密钥以获得增强体验

### 基本操作

#### 1. 开始对话
- 进入AI对话界面
- 选择AI引擎（可选，使用默认模式即可）
- 在输入框中输入您的问题

#### 2. 数据查询示例
```
- "查看所有员工"
- "显示学生列表" 
- "数据库概览"
- "查询班级信息"
- "显示部门信息"
```

#### 3. 数据分析示例
```
- "分析员工分布情况"
- "学生性别比例分析"
- "班级规模分析"
- "学生年龄分布分析"
- "生成综合分析报告"
```

#### 4. 数据管理示例
```
- "添加一名员工"
- "删除某个学生"
- "新增班级信息"
```

## 🛠 技术架构

### 后端组件
- **AgentService**：AI Agent核心服务，负责意图识别和工具调用
- **DatabaseQueryTool**：数据库查询工具，提供数据查询能力
- **DataAnalysisTool**：数据分析工具，提供统计分析能力
- **CrudOperationTool**：CRUD操作工具，提供数据管理能力
- **ChatController**：对话控制器，处理API请求

### 前端组件
- **Chat.vue**：对话界面，集成AI Agent功能
- **实时消息传递**：支持即时对话体验

## 📊 意图识别规则

系统会自动识别以下意图类型：

| 意图类型 | 关键词 | 功能描述 |
|---------|--------|----------|
| QUERY | 查询、查看、显示、所有 | 数据查询功能 |
| ANALYSIS | 分析、报告、分布、比例 | 数据分析功能 |
| CREATE | 添加、新增、创建 | 数据添加功能 |
| DELETE | 删除、移除 | 数据删除功能 |
| CHAT | 其他 | 通用对话功能 |

## 🚀 高级功能

### API增强模式
- 配置AI API密钥后，可以获得更自然、更专业的回复
- AI会对基础数据查询结果进行优化和格式化

### 会话管理
- 支持多个对话会话
- 自动记录每个会话的消息数量
- 可随时切换或删除历史会话

## 💡 提示与技巧

1. **清晰表达**：使用明确的词语表达您的需求
2. **具体查询**：尽可能具体地描述您想查询的信息
3. **分析指令**：使用"分析"、"报告"等词触发分析功能
4. **数据管理**：使用"添加"、"删除"等词触发数据管理功能

## 🔧 故障排除

### 常见问题
- **无法获取数据**：检查数据库连接和数据是否存在
- **AI回复异常**：检查API密钥配置（如果使用增强模式）
- **响应缓慢**：检查系统资源和数据库性能

### 错误处理
- 系统会自动捕获异常并提供友好的错误信息
- 所有操作都有适当的错误处理机制
